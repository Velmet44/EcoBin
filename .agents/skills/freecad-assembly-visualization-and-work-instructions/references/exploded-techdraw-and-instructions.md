# Exploded views, TechDraw, and instructions

Native Assembly can store multiple `Exploded_View` objects inside `Exploded_Views`. Each view contains Move objects with occurrence references and Normal/Radial transforms. The exploded transform is a view state; assembled positions return after edit.

Select an `Exploded_View` and use TechDraw `Insert View` to place it on a page. TechDraw supports technical pages, annotations and PDF/SVG/DXF export. Validate callout attachment after geometry/topology changes and visually inspect every exported page.

Connector lines and explode direction communicate association. Work instructions still require an independently verified insertion/removal path, tool access, torque/locking/adhesive details, safety and inspection acceptance.
