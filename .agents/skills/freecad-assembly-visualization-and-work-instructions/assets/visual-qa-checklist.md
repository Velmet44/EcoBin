# Visual QA checklist

- [ ] Root/child/configuration/BOM hashes match the contract.
- [ ] Frame count, numbering, time order, joint values, FPS and duration match.
- [ ] First, last and every critical pose were reviewed.
- [ ] Camera/projection/resolution/background/display state are controlled.
- [ ] No clipping, flicker, false intersection, z-fighting or hidden required item.
- [ ] Motion is not described as collision or dynamics proof.
- [ ] Exploded transforms reset to authoritative assembled placements.
- [ ] Occurrences, find numbers, quantities, connector lines and parts list reconcile.
- [ ] Tools, torque/process, consumables, safety and inspection are legible.
- [ ] Meaning is not conveyed by color alone; print/localization checks pass.
- [ ] TechDraw and exported PDF/SVG were visually inspected.
- [ ] Source PNGs, media, manual and QA report hashes are recorded.
