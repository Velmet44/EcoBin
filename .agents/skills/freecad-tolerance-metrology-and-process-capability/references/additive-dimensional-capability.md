# Additive dimensional capability

There is no universal FDM, SLA, SLS, MJF, binder-jet, or metal-PBF tolerance. Capability varies with the exact machine, material lot, parameter set, orientation, build position, geometry, feature size, support strategy, thermal history, post-processing, conditioning, and measurement.

Use representative artifacts/coupons to characterize size, form, location, surface, holes, pins, walls, slots, angles, overhangs, and build-volume effects. Preserve the build file, machine state, parameter revision, positions/orientations, raw measurements, uncertainty, and before/after compensation evidence.

ISO/ASTM 52910:2018 gives general design guidance but explicitly does not supply process- or material-specific solutions. ISO/ASTM 52902:2023 covers test artifacts for AM system geometric capability assessment and calibration. NIST’s AM test artifact guidance requires documenting process settings and measuring deviations.
