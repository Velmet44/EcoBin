## Essential FreeCAD Glossary


| Term | FreeCAD Definition |
| :--- | :--- |
| **B-Rep** | Boundary Representation. A CAD solid modeling methodology representing 3D volumes by their bounding vertices, edges, wires, faces, and shells. |
| **Body (PartDesign::Body)** | A container object in PartDesign that holds an ordered sequence of features forming a single, continuous solid. |
| **CSG** | Constructive Solid Geometry. Modeling by combining primitive shapes (cubes, cylinders, spheres) using Boolean operations (Union, Cut, Intersection). Used primarily in the Part workbench. |
| **DAG** | Directed Acyclic Graph. The mathematical dependency model FreeCAD uses to recompute objects in topological order without circular loops. |
| **Datum Object** | Reference geometry (Datum Plane, Datum Line, Datum Point, Coordinate System) used to stably attach sketches and features independently of model faces. |
| **Degrees of Freedom (DOF)** | In Sketcher, the number of independent variables (coordinates, angles, distances) that are not yet constrained by geometric or dimensional constraints. |
| **Feature** | A parametric step in the design history (e.g. Pad, Pocket, Fillet, Boolean). |
| **FeaturePython** | A custom parametric object authored in Python using a proxy class with xecute() and dynamic App::Property definitions. |
| **OpenCASCADE (OCCT)** | The open-source C++ geometric modeling kernel that powers FreeCAD's 3D B-Rep engine. |
| **PlaneGCS** | Planar Geometric Constraint Solver. The numerical solver engine powering FreeCAD Sketcher. |
| **ShapeBinder / SubShapeBinder** | A PartDesign tool that brings reference geometry from another Body or Part into the active Body safely, preventing external breaks. |
| **Tip** | The currently active end-feature in a PartDesign Body. Operations are added on top of the Tip. |
| **TNP** | Topological Naming Problem. Internal renumbering of faces/edges by the CAD kernel when upstream geometry changes. |
